Local AI and agents

Run models. Build with them.

Desktop and mobile apps and services for working with local and cloud models.

macOS · Apple Silicon

LLMTray

A native Mac app for local AI: chat with tools, browse and download models, generate and edit images, and create music. Serves OpenAI- and Anthropic-compatible APIs for your apps and coding agents.

GitHub ↗ Website ↗ App Store ↗

Windows 11 · x64 and ARM64

LLMTray for Windows

The Windows port of LLMTray on llama.cpp: download GGUF models from Hugging Face or Kaggle, serve them through the same OpenAI-compatible API, and chat with tools, projects and memory from the notification area.

GitHub ↗ Download ↗

iPhone · iPad

LLMTray for iPhone and iPad

Chat with a model, ask about a photo, or dictate a question: the model answers on the device itself, with no account and no cloud. Requires iOS 26 or later.

App Store ↗

Go · Terminal agent

ipsupport-code

A lightweight coding agent for local and cloud models. Plan and auto modes, workspace permissions, a built-in risk check, MCP, skills, sub-agents, and lessons saved between runs.

GitHub ↗ Website ↗

Go · Self-hosted gateway

AirLLM

Route agents to language models through one gateway, with model policies, usage limits, provider fallback, token and cost metering, prompt scanning for secrets and PII, and an admin console.

GitHub ↗ Website ↗

MCP connectors

Connect assistants to your daily work.

Tools for any MCP client on macOS, built with JavaScript for Automation and no extra runtime dependencies.

macOS · MCP

Apple Mail, Calendar & Notes

Read, search and organize mail, prepare replies, manage calendar events, and keep notes through the apps on your Mac. Includes read-only mode and previews for supported write operations.

GitHub ↗

macOS · MCP

Seafile MCP

Browse, search and organize Seafile libraries, transfer files, restore versions, and manage share links. Browser sign-in stores the token in macOS Keychain; read-only mode is available.

GitHub ↗

Infrastructure and distribution

Put your own hardware to work.

Kubernetes tools for shared GPUs and on-demand compute, plus packages for installing our apps.

Go · Kubernetes DRA

dra-driver-dri

Share GPUs between Kubernetes pods by requested VRAM. Exposes Linux DRM render nodes through CDI for Vulkan inference, including older AMD hardware without ROCm. VRAM requests guide scheduling; they are not hard memory limits.

GitHub ↗

Go · Kubernetes autoscaling

plugpool

A cluster-autoscaler provider for bare-metal machines powered by ESPHome smart plugs. Boots nodes when capacity is needed and shuts them down before cutting power, with support for scaling to zero.

GitHub ↗

Homebrew · macOS and Linux

Homebrew tap

Install LLMTray or LLMTray Full on Mac, and ipsupport-code (also available as ipco) on macOS and Linux. Formulae and casks track stable product releases.

GitHub ↗

Scoop · Windows

Scoop bucket

Install LLMTray for Windows (the portable build) and ipsupport-code with Scoop: scoop bucket add ipsupport https://github.com/ipsupport-llc/scoop-bucket, then scoop install ipsupport/llmtray.

GitHub ↗
