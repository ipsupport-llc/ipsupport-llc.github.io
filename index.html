Products and public projects

The products and tools behind our AI work.

ipsupport-code

Local-first coding agent with a terminal UI, tool execution, workspace permissions, model switching, sub-agents, and lessons that persist between runs.

ipsupport-airllm

Secure LLM control plane for internal agents: model policy, usage limits, routing, DLP for secrets and PII, BERT-NER sidecar, capture, audit, alert webhooks, and an admin console.

LLMTray

Native macOS menu bar app for running local LLMs with mlx-lm on Apple Silicon. Start and stop the server, browse and download Hugging Face models, and chat.

Line One Agent

B2B voice-AI SaaS for inbound and outbound calls: multilingual AI agents, call transcription, structured outcomes, workspace management, and encrypted tenant data.

sipmesh

Kubernetes-native SIP/RTP and AI voice platform. The code is being prepared for a public release; for now we can discuss the architecture and roadmap.

terraform-minikube-platform

Multi-tenant hosting platform — Terraform-first, Cloudflare Tunnel for public ingress, shared MySQL / PostgreSQL / Redis / Ollama, single-operator by design.

mcp-weather-simple

MCP tool server for weather, web search, and small utilities. The lean catalog mode delivers full functionality at -79% prompt overhead.
